# RubexOps V2

Enterprise Rubber Procurement & Operations Management System

RubexOps is a Windows desktop application developed to manage procurement contracts, purchases, inventory calculations and operational workflows for Natural Rubber Field Coagulum (NRFC).

## Core Principle

Excel stores data.

Python performs calculations.

C# displays information.

No business logic depends on Excel formulas.
